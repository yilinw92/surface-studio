# Attribution

The editable workbench and curve/mesh/shader code were prepared for this portfolio with AI assistance. The standalone HTML wrapper was exported using Codex's visualization renderer and is retained as an offline template so the repository can rebuild without a Codex installation. It provides preview framing, local UI-state compatibility and icon initialization; it is not presented as a native graphics engine.

The exported UI includes a small set of [Lucide](https://lucide.dev/) icons. Their upstream license is preserved in `third_party/lucide-LICENSE`. There are no npm packages, third-party CAD kernels, model assets or external script downloads required at runtime.

The future Dear ImGui / GLM / OpenGL native implementation is a roadmap item. Those libraries are not currently included or used to claim C++ functionality.
